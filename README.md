## 📌 About

This repository contains my **LeetCode SQL solutions**.

Solutions are automatically synced from **LeetCode** using **LeetHub**, while a custom **GitHub Actions** workflow keeps the repository organized by:

- ✅ Keeping **only SQL solutions**
- ✅ Removing non-SQL files automatically
- ✅ Versioning multiple submissions for the same problem
- ✅ Maintaining a clean repository structure

---

## ⚙️ Automation

### 🔹 LeetHub Sync

This repository is connected to **LeetHub**, which automatically pushes accepted LeetCode submissions whenever I solve a problem.

---

### 🔹 Custom GitHub Workflow

After every push to the `main` branch, a custom GitHub Action automatically processes new submissions.

### Workflow Features

- Removes non-SQL files generated by LeetHub.
- Preserves repository configuration files.
- Keeps the root `README.md`.
- Automatically versions SQL submissions:
  ```
  Solution.sql
        ↓
  Solution_1.sql
  Solution_2.sql
  Solution_3.sql
  ...
  ```
- Deletes empty directories after cleanup.
- Automatically commits and pushes processed changes back to the repository.
